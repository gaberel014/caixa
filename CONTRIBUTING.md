# Como contribuir

Obrigado por querer melhorar o Caixa.

## Antes de começar

- Abra uma issue para descrever o problema ou a ideia.
- Para mudanças maiores, espere o alinhamento dos mantenedores antes de investir tempo na implementação.
- Mantenha a experiência em português claro e evite coletar dados que o recurso não precisa.

## Como propor uma mudança

1. Faça um fork do repositório.
2. Crie uma branch com um nome curto, como `melhorar-exportacao`.
3. Faça uma alteração pequena e descreva o comportamento esperado.
4. Abra um pull request explicando o problema que resolve e como conferir a mudança.

## Princípios do projeto

- Privacidade por padrão.
- Sem serviços pagos obrigatórios para usar as funções principais.
- Interface acessível em celular e computador.
- Dados e limitações explicados sem prometer precisão contábil.
